## What population am I sampling from?

### Population description

Standard normal. The important characteristics of it is that it's a normal population which means we should expect a normal distribution

### Theoretical mean and standard deviation

We are assuming that the population mean is $\mu = 0$, and its standard deviation is $\sigma = 1$ as that is typical of a normal population.

### CLT assumptions

We are assuming that the observations with a sample are independent.

The original population follows a bell curve with few massive outliers as seen below.

```{r}

     main = "Original population: Standard normal",
     xlab = "Individual observation")

curve(dnorm(x, mean = 0, sd = 1),
      add = TRUE, col = "red", lwd = 2)
```

## What did I expect before running the simulation?

Because the population is normal, I expect it to be normally distributed which means for the Q-Q graph to follow the line and to see a bell-curve which will only become more precise as n increases.

## Which sample sizes did I investigate, and why?

### Sample sizes

I investigated n = 1, 2, 3, 5, 10, 20, 30, 50, and 100.

We are starting from the lowest possible starting size, which is 1, and seeing how major changes impact it. The gap from 1 to 2 should be more impactful than the gap from 100 to 101, so we start with small increases and then towards the end do bigger ones.

### Number of repetitions

I used B = 10,000 repetitions for each sample size.

B is used to represent the amount of repetitions of the Monte Carlo Simulations. 10,000 was chosen not only because it was the example used but also because it's a large number which allows for many means to be represented.

## How did I define “approximately normal”?

When looking at the histogram, an average mean which differs from the normal by less than 1% (±0.01) can be considered normal. While it's not the most precise, I am hoping that if the percent cannot be represented without using fractions then that means it will be close enough

## When was the sampling distribution approximately normal?

n = 1

Even with an n of 1, the simulated mean was 0.0013 which is 0.13% away from 0 which is the expected mean.

## Why did I choose that value?

### Simulation code and results

```{r}
sample_sizes <- c(1, 2, 3, 5, 10, 20, 30, 50, 100)
results <- data.frame()

normal_quartiles <- qnorm(c(0.25, 0.75))

for (n in sample_sizes) {
  set.seed(seed)
  means <- replicate(B, mean(rnorm(n)))
  
  # Get Q-Q point coordinates without drawing a plot
  qq_points <- qqnorm(means, plot.it = FALSE)
  
  # Reconstruct the reference line drawn by qqline()
  observed_quartiles <- as.numeric(
    quantile(means, c(0.25, 0.75))
  )
  
  slope <- diff(observed_quartiles) / diff(normal_quartiles)
  intercept <- observed_quartiles[1] -
    slope * normal_quartiles[1]
  
  # Measure vertical departures from the line
  line_values <- intercept + slope * qq_points$x
  differences <- qq_points$y - line_values
  
  qq_rmse <- sqrt(mean(differences^2))
  normalized_qq_rmse <- qq_rmse / slope
  
  results <- rbind(
    results,
    data.frame(
      n = n,
      simulated_mean = mean(means),
      simulated_SE = sd(means),
      theoretical_SE = 1 / sqrt(n),
      QQ_RMSE = qq_rmse,
      normalized_QQ_RMSE = normalized_qq_rmse
    )
  )
  
  if (n %in% c(1, 2, 3, 5, 10, 30, 100)) {
    hist(means, breaks = 40,
         main = paste("Sample means: n =", n),
         xlab = "Sample mean")
    
    qqnorm(means, main = paste("Normal Q-Q plot: n =", n))
    qqline(means, col = "red")
  }
}

knitr::kable(results, digits = 4)

The gap from 1 to 2 should be more impactful than the gap from 100 to 101, so we start with small increases and then towards the end do bigger ones. 125, 150, and 200 were necessary as even as high as 100 it did not become normal.

### Number of repetitions

I used B = 10,000 repetitions for each sample size.

B is used to represent the amount of repetitions of the Monte Carlo Simulations. 10,000 was chosen not only because it was the example used but also because it's a large number which allows for many means to be represented.

## How did I define “approximately normal”?

When looking at the histogram, an average mean (the mean of the means in the histogram) which differs from the expected mean (1) by less 0.01 can be considered normal. While it's not the most precise, I am hoping that if, when converted to a percent (1%) it cannot be represented without using fractions then that means it will be close enough. While this mainly accounts for the center, the normalized RMSE accounts for the tails. Since the tails make up a minority of the data, deviation less than 0.05 can still be considered normal as while it does deviate a fair amount, at this level of deviation the theoretical max any point can deviate is by 5. While that is a lot, it is extremely uncommon as that would mean each other gap has a deviation of 0 units. An average gap of 0.05 is acceptable as it's half of a tenth.

### Simulation code and results

```{r}
sample_sizes <- c(1, 2, 3, 5, 10, 20, 30, 50, 100, 125, 150, 200)
results <- data.frame()

normal_quartiles <- qnorm(c(0.25, 0.75))

for (n in sample_sizes) {
  set.seed(seed)
  means <- replicate(
    B,
    mean(rexp(n, rate = 1))
  )
  
  # Get Q-Q point coordinates without drawing a plot
  qq_points <- qqnorm(means, plot.it = FALSE)
  
  # Reconstruct the reference line drawn by qqline()
  observed_quartiles <- as.numeric(
    quantile(means, c(0.25, 0.75))
  )
  
  slope <- diff(observed_quartiles) / diff(normal_quartiles)
  intercept <- observed_quartiles[1] -
    slope * normal_quartiles[1]
  
  # Measure vertical departures from the line
  line_values <- intercept + slope * qq_points$x
  differences <- qq_points$y - line_values
  
  qq_rmse <- sqrt(mean(differences^2))
  normalized_qq_rmse <- qq_rmse / slope
  
  results <- rbind(
    results,
    data.frame(
      n = n,
      simulated_mean = mean(means),
      simulated_SE = sd(means),
      theoretical_SE = 1 / sqrt(n),
      QQ_RMSE = qq_rmse,
      normalized_QQ_RMSE = normalized_qq_rmse
    )
  )
  
  if (n %in% c(1, 2, 3, 5, 10, 20, 30, 50, 100, 125, 150, 200)) {
    hist(
      means,
      breaks = 40,
      probability = TRUE,
      main = paste("Sample means: n =", n),
      xlab = "Sample mean",
      ylab = "Density"
    )
    
    curve(
      dnorm(x, mean = 1, sd = 1 / sqrt(n)),
      add = TRUE,
      col = "red",
      lwd = 2
    )
    
    qqnorm(means, main = paste("Normal Q-Q plot: n =", n))
    qqline(means, col = "red")
  }
}

### Q-Q plot evidence

The Q-Q plot is the clearest case demonstrating the issue with the exponential population. ### Numerical evidence

Keeping in mind that the mean must be within a 0.01 tolerance of 1.00, the population did a great job of that. However it was clearly not normally distributed which can be seen through the Q-Q plot's RMSE. The standard error was well within what was expected to, making the RMSE the main check for normality.

### Justification for my selected sample size

n = 125 is the best choice for when it becomes normal as only then does it not only visually look normal in the histogram, but also numerical becomes normal due to finally having a Q-Q RMSE within the bounds of normality.
